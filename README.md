# Tangram Geometry Lab

A free student tool by Winsome Mundy: measure the seven tangram pieces, compare congruent and similar figures, and prove the pieces add up to the square. Live at tangram.winsomemundy.com, linked from winsomemundy.com/tools.

Built on the Winsome Mundy design system (`@winsomemundy/design-system`, pinned in `package.json`) using its Tool Page frame and components. The lesson's own pieces (diagrams, answer tables, questions, answer key) are styled in `index.html`.

## Files

- `index.html`: the tool. The only file to edit by hand.
- `tangram-geometry-lab.html`: the self-contained version published as a Claude artifact, generated by `npm run artifact`. Don't edit it directly.
- `build.mjs`: assembles `dist/` for Vercel: the page, the design system's stylesheets in `dist/ds/`, and the worksheet PDF as `tangram-geometry-lab-worksheet.pdf`, which the page's download button links to.
- `tangram-worksheet-print.html` and `Tangram Geometry Lab Worksheet.pdf`: the printable worksheet. If you change the worksheet, export a new PDF over the old one and update the page count and size next to the download button in `index.html`.

## Release a change

1. Edit `index.html`.
2. Run `npm run artifact` to regenerate `tangram-geometry-lab.html`.
3. Publish `tangram-geometry-lab.html` to the existing artifact link so the link stays the same.
4. Commit and push to `main`. Vercel builds and deploys automatically.
5. Open tangram.winsomemundy.com and confirm the change.

## Take a new design system release

1. Run `npm install github:winsomemundy/design-system#<new tag>`. This updates the tag in `package.json` and the pinned commit in `package-lock.json` together; a plain `npm install` keeps the old commit.
2. Check `node_modules/@winsomemundy/design-system/package.json` shows the new release.
3. Follow the release steps above from step 2, and commit `package.json` and `package-lock.json` too.
